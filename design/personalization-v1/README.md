# کارت پیشنهادهای شخصی — نسخهٔ ۱ (آرشیوشده)

> ⚠️ **این نسخه از داشبورد حذف شده است** (۱۴۰۵/۰۷/۱۹).
> دلیل حذف: قرار است در فاز بعدی، نسخهٔ **تخصصی و مبتنی بر یادگیری ماشین**
> جایگزین شود. این پوشه فقط مرجع و نقطهٔ شروع کار آینده است.

## چرا حذف شد؟

نسخهٔ ۱ فقط بر اساس **نقش انتخابی در فرم ثبت‌نام** محتوا را عوض می‌کرد
(نگاشت ایستا و دستی). این برای نمایش کافی بود ولی:

- علایق واقعی کاربر را نمی‌شناخت (فقط رشته/نقش اولیه)
- از رفتار واقعی استفاده نمی‌کرد (پرسش‌های پرتکرار، اسناد بررسی‌شده، موضوعات پیگیری‌شده)
- نتیجه‌گیری «شخصی» در آن، بیشتر قالبی بود تا داده‌محور

## مسیر پیشنهادی برای نسخهٔ ML

| لایه | نقش | ورودی | خروجی |
|---|---|---|---|
| **لایهٔ ۱ — جمع‌آوری سیگنال** | ثبت رخدادهای رفتاری به‌صورت محلی | پرسش‌ها، اسناد بازشده، جعبه‌های کلیک‌شده، دوره‌های دیده‌شده | پروفایل رفتاری محلی |
| **لایهٔ ۲ — استخراج ویژگی** | تبدیل سیگنال خام به بردار ویژگی | پروفایل رفتاری | بردار علاقه (embedding) |
| **لایهٔ ۳ — رتبه‌بندی** | انتخاب محتوای هر جعبه | بردار علاقه + بردار محتوا | ترتیب محتوای پیشنهادی |
| **لایهٔ ۴ — توضیح‌پذیری** | گفتن دلیل پیشنهاد به کاربر | امتیازها | «چون اخیراً دربارهٔ X پرسیدی» |

### ملاحظات انطباقی (غیرقابل مذاکره)

- **برچسب «نمونه»** روی هر محتوای پیشنهادی (قاعدهٔ H2/C5)
- **بدون آمار ساختگی** — اگر امتیاز یا درصدی نمایش داده می‌شود، باید از دادهٔ واقعی همان کاربر باشد
- **بدون تبلیغ پنهان** — محتوای تجاری جدا و برچسب‌گذاری‌شده بماند (تصمیم D2)
- **محلی و شفاف** — داده‌های رفتاری کاربر نباید بدون رضایت صریح جایی ارسال شود (قاعدهٔ E3)
- **حق حذف** — کاربر باید بتواند پروفایل رفتاری خود را پاک کند

## فایل‌های این آرشیو

| فایل | محتوا |
|---|---|
| `PersonalizedCard.tsx` | کارت چهار‌بخشی: موضوعات رشته / دوره‌ها / منابع و کتب / تبلیغات |
| `personalized.ts` | داده‌های نقش‌محور: `PERSONAL_TOPICS`، `ROLE_COURSES`، `ROLE_RESOURCES` |

## الگوی کامپوننت قابل استفادهٔ مجدد

ساختار چهار‌بخشی کارت بالا برای نسخهٔ ML هم قابل استفاده است؛
فقط محتوای هر بخش از موتور رتبه‌بندی می‌آید به‌جای نگاشت ایستا:

```tsx
// الگوی پیشنهادی برای لایهٔ رتبه‌بندی
const ranked = useRankedContent(userId);        // لایهٔ ۳
<PersonalizedCard
  topics={ranked.topics}                        // از مدل
  courses={ranked.courses}
  resources={ranked.resources}
  ads={ranked.ads}
  explain={(item) => `چون اخیراً دربارهٔ «${item.topic}» پرسیدی`}  // لایهٔ ۴
/>
```

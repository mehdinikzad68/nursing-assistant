# برنامهٔ شروع توسعه — نسخهٔ اولیهٔ نمایشی (Prototype)

- **عنوان پروژه:** پروتوتایپ نمایشی دستیار حقوقی پرستار
- **وضعیت:** 🟡 فقط نمایش داخلی/پرزنت — **بدون انتشار عمومی، بدون دامنه، بدون تبلیغ**
- **منبع محتوا:** داده‌های عمومی و نمونه (Synthetic) — برچسب `دادهٔ نمونه` روی هر عدد
- **ردیف Trace:** `T06` (طراحی) · `T04` (امکانات) · `T05` (قالب پاسخ) · `F3` (برنامهٔ اصلی MVP)

> ⚠️ **تفاوت با نقشهٔ راه:** این فایل مسیری «کناری» برای نمایش است، نه شروع رسمی فاز F0–F6. قابلیت‌های این پروتوتایپ از دامنهٔ F3 «قرض» گرفته شده‌اند و با گیت G0/G3 همگام نیستند — در پرزنت نباید به‌عنوان «محصول نهایی» معرفی شود.

## ۱. هدف و غیرهدف

| ✅ هدف (Do) | ❌ غیرهدف (Don't) |
|---|---|
| دموی کلیک‌پذیر از ۵ سناریوی اصلی برای پرزنت | هوش مصنوعی واقعی / RAG / اتصال LLM |
| نمایش کیفیت طراحی و جریان کاربری | پایگاه داده، سرور، احراز هویت واقعی |
| دادهٔ نمونهٔ قابل باور اما صریحاً «برچسب‌خورده» | انتشار، خرید دامنه، ثبت‌نام کاربر واقعی |
| قابل اجرا روی لپ‌تاپ و یک نشست آنلاین | پرداخت، اتصال نظام پرستاری، پشتیبانی |

## ۴. پشتهٔ فناوری (هم‌راستا با T08)

| لایه | انتخاب برای پروتوتایپ | دلیل |
|---|---|---|
| فرانت‌اند | **Next.js (App Router) + Tailwind** | همان مسیر F3؛ PWA بعداً |
| داده | **JSON استاتیک در `/data/mock/*.json`** | بدون سرور؛ هر داده برچسب `sample: true` |
| هوش مصنوعی | **پاسخ‌های ازپیش‌نوشته‌شده (Canned)** روی هر سناریو + تایپینگ افکت شبیه‌سازی‌شده | کیفیت نمایشی بدون هزینهٔ توکن |
| احراز هویت | هیچ (مسیر بدون ثبت‌نام پیش‌فرض) | سادگی |
| میزبانی | فقط `localhost` / build محلی / صورت نیاز Netlify خصوصی با لینک مخفی | انتشار ممنوع |

| مایلستون | مدت | خروجی | معیار پذیرش |

| **M0 — زیرساخت** | ۱–۲ روز | ریپو، قالب Next.js، Design System (رنگ/فونت/کامپوننت پایه)، تم، ساختار پوشه | `npm run dev` بالا می‌آید؛ تم روشن/تیره و RTL کار می‌کند |

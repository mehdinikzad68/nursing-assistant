# F4 — اعتماد، امنیت و کنترل کیفیت (پیش از عرضهٔ عمومی)

- **بازه:** هفتهٔ ۱۳ تا ۱۸ (موازی با پایان F3) · **گیت خروج:** G4 — **بدون عبور از این گیت، عرضهٔ عمومی ممنوع است**
- **هدف:** حذف ریسک‌هایی که یک خطایشان پروژه را تمام می‌کند: ادعای وکالت، پاسخ hallucinated، افشای سند بیمارستان، لو رفتن هویت.
- **Trace:** T10 (۱۰ نقطه کور) · T09 (امنیت و حریم) · T05 (لحن و سطوح قطعیت) · T06 (دسترس‌پذیری) · T08 (Human-in-the-Loop)

> این فاز «قابلیت» اضافه نمی‌کند؛ فقط مجوز عمومی‌شدن را تولید می‌کند. اگر زمان کم آمد، **تاریخ عرضه عقب می‌افتد، دامنهٔ این فاز نه**.

## ۲. گیت خروج G4 (شرط‌های عبور — همگی الزامی)

- [ ] تأییدیهٔ کتبی مشاور حقوقی بر ToS/دیسکلایمر/صفحۀ «حدود ما».
- [ ] صفر تخلف لفظی از فهرست ممنوعه در ۵۰۰ خروجی نمونه.
- [ ] صفر استناد نادرست در Golden Set + سؤالات تله؛ «عدم‌اطمینان درست» ≥ ۹۰٪.
- [ ] گمنام‌سازی: صفر باقی‌ماندهٔ هویتی در ۲۰ سند + شکست حملهٔ بازسازی هویت.
- [ ] تست نفوذ: صفر بحرانی/بالای باز.
- [ ] حذف دادهٔ کاربر در عمل (نه فقط در سیاست) اثبات شود.
- [ ] WCAG 2.2 AA روی ۵ صفحهٔ اصلی بدون ایراد A.
- [ ] مسیر ارجاع انسانی + SLA واقعی‌سازی‌شده (D10) امضاشده باشد.
- [ ] سناریوی قطعی/کندی مدل با پاسخ ایمن آزموده شود.

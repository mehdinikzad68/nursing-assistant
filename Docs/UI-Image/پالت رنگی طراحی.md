برای این محصول، پالت مناسب یک **سیستم آرام و قابل‌اعتماد مبتنی بر سبز-آبی** است؛ نه آبی تند حقوقی و نه قرمز دائمی هشدار. رنگ اصلی برای اقدام و راهنمایی، رنگ‌های خنثی برای خوانایی، و رنگ‌های معنایی فقط برای وضعیت استفاده می‌شوند.

متن معمولی باید حداقل کنتراست **۴٫۵:۱** و اجزای مهم غیرمتنی مانند مرز ورودی، آیکن و نشانگر وضعیت حداقل **۳:۱** داشته باشند.\[

## **اصول استفاده از رنگ**

* رنگ اصلی فقط برای اقدام اصلی، لینک، فوکوس و بخش فعال استفاده شود.  
* قرمز فقط برای مهلت نزدیک، خطا یا هشدار واقعی باشد؛ نه برای برند یا دکمه‌های دائمی.  
* سبز به‌معنای «ثبت شد» یا «آماده بازبینی» باشد، نه «حق با شماست» یا «پرونده موفق شد».  
* زرد/کهربایی برای «نیازمند تکمیل اطلاعات» استفاده شود.  
* آبی فقط برای منابع، استناد و اطلاعات تکمیلی باشد تا با رنگ اصلی اشتباه نشود.  
* وضعیت را فقط با رنگ نشان ندهید؛ همیشه متن یا آیکن هم داشته باشد.  
* حلقه فوکوس کیبورد باید همیشه واضح و پایدار باشد.

## **معنای ثابت وضعیت‌ها**

* **خاکستری:** پیش‌نویس، آرشیو یا بدون اقدام.  
* **آبی:** منبع، توضیح یا اطلاعات تکمیلی.  
* **کهربایی:** اطلاعات ناقص یا نیازمند بازبینی کاربر.  
* **سبز:** ثبت شد، آماده بازبینی یا اقدام انجام شد.  
* **قرمز:** مهلت نزدیک، خطای اعتبارسنجی یا مانع جدی.  
* **سبز-آبی:** اقدام اصلی، حریم خصوصی و هویت محصول.

سبز را برای «نتیجه به نفع کاربر» استفاده نکنید. این تمایز برای جلوگیری از اعتماد کاذب در محصول حقوقی ضروری است.

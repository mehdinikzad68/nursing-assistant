# ROLES & AGENTS — نقش‌ها و ایجنت‌ها

> تیم AI-Driven برای ساخت **نسخهٔ اول نمایشی**. هر نقش یک ایجنت اصلی + یک بازبین انسانی دارد.
> هیچ ایجنتی روی فایل کارِ ایجنت دیگر نوشته نمی‌کند.

---

## ۱. نقش‌های انسانی (حداقل‌هایی که AI نمی‌تواند جایگزین شود)

| نقش | مسئولیت غیرقابل‌واگذاری | چرا AI نمی‌تواند |
|---|---|---|
| **PO / تصمیم‌گیرنده** | D1 (برش MVP)، D2 (لحن)، داوری ابهام‌ها | قضاوت ارزشی و مسئولیت حقوقی (قانون ۰) |
| **بازبین حقوقی** | تأیید لحن، قالب پاسخ، برچسب نمونه | خطای حقوقی در این پروژه پیامد انسانی دارد |
| **مالک محصول/مالک تغییر** | تأیید نهایی هر PR | اختیار انتشار |

> نکته: در نسخهٔ نمونه، نقش «بازبین حقوقی» سبک است (۲ ساعت در هفته) اما **الزامی** — چون قانون H1–H5 بدون بازبینی انسانی قابل اتکا نیستند.

## ۳. جریان کار (Workflow)

```
PO تعریف می‌کند  →  agent-legal بررسی می‌کند  →  ایجنت‌های اجرایی می‌سازند
       ↑                                                      ↓
 agent-review بازبینی  ←  agent-a11y تست  ←  agent-test تست  ←  بازبین انسانی تأیید
```

**ترتیب اجرای اسپرینت ۱:**
1. `agent-po` → بستهٔ کار
2. `agent-legal` → تأیید یا اصلاح
3. `agent-research` + `agent-design` → پایهٔ بصری (موازی)
4. `agent-content` + `agent-copy` → متن‌ها (موازی با ۳)
5. `agent-ui-core` → صفحهٔ اصلی
6. `agent-ui-extra` → صفحات جانبی
7. `agent-a11y` + `agent-test` → تست
8. `agent-review` + بازبین انسانی → تأیید

## ۴. قالب فایل هر ایجنت

هر ایجنت یک فایل `ai-agents/<name>.md` دارد با این ساختار:

```
# <نام نقش>
## مأموریت
## ورودی‌ها (کدام فایل‌ها را می‌خواند)
## خروجی‌ها (کدام فایل‌ها را می‌نویسد — فقط این‌ها!)
## قوانینی که باید رعایت کند (ارجاع به PROJECT-RULES)
## ممنوعیت‌ها (چه کاری هرگز نکند)
## معیار پذیرش کارش
```

## ۵. تقسیم مالکیت فایل‌ها (قانون ۷)

```
نسخه-اول-نمایشی/
├── docs/           → فقط یک ایجنت هر فایل
├── ui/
│   ├── tokens.css  → agent-design
│   ├── app.css     → agent-ui-core
│   ├── index.html  → agent-ui-core
│   ├── landing.html→ agent-ui-extra
│   └── payslip.html→ agent-ui-extra
└── ai-agents/      → فقط یک ایجنت هر فایل
```

تعارض = بازبینی انسانی تصمیم می‌گیرد، ایجنت‌ها چانه نمی‌زنند.

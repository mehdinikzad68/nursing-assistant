# نسخهٔ اول — نمونه (Prototype v0)

**هدف:** نسخهٔ اولیهٔ قابل‌نمایش رابط کاربری، با **دادهٔ عمومی و نمونه**، بدون ادعای دقت حقوقی.

**تاریخ شروع:** ۱۴۰۵/۰۷/۰۸

---

## ۱. تعریف «نمونه» (غیرقابل‌دورزدن)

نسخهٔ اول **فقط** یک چیز است: **رابط کاربری + جریان گفتگوی نمونه** با داده‌ای که خودمان ساخته‌ایم.

| این نسخه **هست** | این نسخه **نیست** |
|---|---|
| طراحی رابط (UI) بر اساس T06 | پاسخ حقوقی واقعی |
| جریان گفتگوی نمونه با پاسخ‌های ازپیش‌نوشته | بازیابی از پایگاه دانش واقعی |
| دادهٔ ساختگیِ نمونه (سارا / مریم) | استناد به بند قانونی معتبر |
| نمایش ساختار پاسخ ۴ بخشی | تشخیص خطای واقعی در فیش حقوقی |
| واکنش‌گرا و RTL و دارک‌مود | محاسبهٔ اضافه‌کاری |

### برچسب اجباری در محصول
هر جای رابط که پاسخ نمایش داده می‌شود، باید این برچسب دیده شود:

```
🔶 این نسخه نمایشی است — پاسخ‌ها نمونه‌اند و مبنای حقوقی ندارند
```

**چرا این برچسب الزامی است، نه اختیاری:** سند T10 نقطه‌کور ۱ و ۲ — حتی با دادهٔ عمومی، پاسخِ قاطع می‌تواند ادعای وکالت تلقی شود یا به کاربر آسیب بزند. در نسخهٔ نمونه، **ریسک اصلی، برداشت کاربر از پاسخ نمونه به‌عنوان حقیقت است**، نه خطای فنی.

## ۲. محدودهٔ دقیق کار (In Scope)

## ۴. خروجی مورد انتظار

یک پروتوتایپ که با باز کردن `ui/index.html` در مرورگر کار کند و:
- روی گوشی و دسکتاپ خوب دیده شود
- حالت روشن و تاریک داشته باشد
- سه مسیر نمونه را کامل کند (پرسش حقوقی / بررسی فیش / مرخصی)
- هرگز پاسخ را قطعی نشان ندهد

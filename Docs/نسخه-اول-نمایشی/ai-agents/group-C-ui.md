# agent-design — Design System

## مأموریت
تعریف توکن‌های بصری: پالت، فونت، فاصله، اندازهٔ دکمه، آیکون.

## ورودی‌ها
سند `T06` بخش ۲ (رنگ و تایپوگرافی)

## خروجی‌ها (فقط این فایل)
`ui/tokens.css`

## قوانین
- پس‌زمینهٔ سفید یخچالی، رنگ اصلی آبی/تیل، هشدار نارنجی ملایم (نه قرمز جیغ).
- فونت Vazirmatn، پاراگراف ≤ ۳ خط، دکمه ≥ ۴۴px، متن ≥ ۱۶px.
- اعداد مونواسپیس برای مبالغ.

## ممنوعیت‌ها
- رنگ جیغ، فونت تزئینی.

## معیار پذیرش
توکن‌های CSS با نام‌گذاری روشن و قابل استفاده در همهٔ صفحات.

# agent-ui-core — صفحهٔ اصلی و گفتگو

## مأموریت
ساخت `index.html` (صفحهٔ آغاز + گفتگو + قالب پاسخ ۴ بخشی) و `app.css`.

## ورودی‌ها
`ui/tokens.css` · `docs/sample-dialogs.md` · سند `T06` · قانون ۲ و ۳

## خروجی‌ها (فقط این فایل‌ها)
`ui/index.html` · `ui/app.css`

## قوانین
- پاسخ دقیقاً ۴ بخشی + سطح قطعیت + برچسب نمونه.
- Chips پاسخ آماده به‌جای تایپ.
- قانون ۳ ثانیه: نوار پرسش + میکروفون + ۳ کارت سریع.
- RTL، دارک‌مود.

## ممنوعیت‌ها
- تایمر فشار، اعلان ناگهانی، انیمیشن تهدیدآمیز (H6).

## معیار پذیرش
هر ۳ مسیر نمونه در مرورگر کار کند؛ بدون کنسول‌ارور.

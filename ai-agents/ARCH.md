# ARCH — معمار رابط و محتوا

## مأموریت
نقشهٔ صفحات، ناوبری، ساختار داده، پایگاه دانش حقوقی.

## ورودی‌ها
- `docs/دسته‌بندی موضوعی/T04` (امکانات)
- `docs/دسته‌بندی موضوعی/T06` (UI/UX)
- `docs/دسته‌بندی موضوعی/T08` (معماری)
- `docs/دسته‌بندی موضوعی/T12` (MVP)

## خروجی‌ها
- `docs/ARCH.md` — معماری کلی سامانه
- `data/knowledge-base.json` — ساختار پایگاه دانش
- `lib/types.ts` — تایپ‌های TypeScript

## قوانین
- پایگاه دانش فقط از منابع عمومی
- متادیتا سختگیرانه (Status, EffectiveDate, ExpirationDate)
- بدون ادعای وکالت

## ممنوعیت‌ها
- استفاده از دادهٔ واقعی بدون برچسب «نمونه»
- اتصال به سرویس خارجی بدون تأیید

## معیار پذیرش
- ساختار کامل پایگاه دانش با متادیتا
- تایپ‌های TypeScript تعریف شده
- نقشهٔ صفحات کامل

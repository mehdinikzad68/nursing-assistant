# دستیار پرستار — Nursing Assistant

> 🔶 **این نسخه نمایشی است** — پاسخ‌ها نمونه‌اند و مبنای حقوقی ندارند.

دستیار حقوقی و اداری پرستاران — نسخه اول نمایشی با داده‌های عمومی.

## ویژگی‌ها

- ✅ صفحه آغاز با قانون ۳ ثانیه
- ✅ گفتگوی تخصصی با قالب پاسخ ۴ بخشی
- ✅ بررسی فیش حقوقی (نمونه)
- ✅ لندینگ پیج ۷ بخشی
- ✅ حالت تاریک (شیفت شب)
- ✅ راست‌به‌چپ با فونت Vazirmatn
- ✅ بدون ثبت‌نام اجباری

## شروع

```bash
npm install
npm run dev
```

سپس به `http://localhost:3000` برو.

## ساختار پروژه

```
app/                    # صفحات Next.js
  page.tsx             # صفحه اصلی
  chat/page.tsx        # گفتگوی تخصصی
  payroll/page.tsx     # بررسی فیش حقوقی
  landing/page.tsx     # لندینگ پیج
components/ui/         # کامپوننت‌های طراحی
data/                  # داده‌های نمونه
  mock/               # فیش‌ها، نامه‌ها، پاسخ‌های نمونه
  knowledge-base.json # ساختار پایگاه دانش
docs/                  # مستندات پروژه
ai-agents/            # تعریف نقش‌های ایجنت‌ها
```

## قوانین پروژه

- هر پاسخ باید برچسب «نمونه» داشته باشد
- هیچ ادعای وکالت نمی‌شود
- سه سطح قطعیت الزامی است
- بدون دارک‌پترن

## تیم توسعه

| نقش | مسئولیت |
|---|---|
| LEAD | هماهنگی و یکپارچه‌سازی |
| ARCH | معماری و پایگاه دانش |
| DESIGN | طراحی سیستم |
| MOCK | داده‌های نمونه |
| QA | کنترل کیفیت |
| REVIEW | بازبین حقوقی |
